## Daily 8-Hour Plan (Non-Negotiable Structure)

```
Block 1 — DSA (2 hrs)
  • 1–2 problems from DSA-Plan.md, in order
  • If stuck after 30 min → watch NeetCode explanation, understand pattern, re-solve tomorrow
  • Week 1–3: 30–45 min/problem. Week 4+: 45–60 min (harder patterns)

Block 2 — System Design (1 hr)
  • Weeks 1–2: Read 1 new answer from answers/01–15
  • Weeks 3–6: Re-read previous answers, speak them aloud without notes (target: 5 min per Q)
  • Never read passively — explain it out loud as if in an interview

Block 3 — Tech Prep (1 hr)
  • Weeks 1–2: fast-api.md + python_questions.md (rotate daily)
  • Week 2 only: 2 days on pgvector (build semantic search in VidyaTrack)
  • Week 3+: interview/QnA.md, interview/GenAI.md, interview/rapid.md (rotate)

Block 4 — Applications (1 hr)
  • Apply to 2–3 companies from master-list following the day schedule
  • Send 1–2 LinkedIn connection messages to people at applied companies
  • Track status in master-list application tracker

Block 5 — Free / Buffer (3 hrs)
  • Reading around interview topics (not new prep — context reading)
  • GitHub/LinkedIn profile updates
  • Rest, meals, life
  • If an interview is scheduled: use this block for company-specific prep

Total: 8 hrs. DSA + SD + Tech = 4 hrs locked. Applications = 1 hr locked. Rest = flexible.
```
